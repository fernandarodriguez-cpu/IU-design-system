# Mejoras Futuras para el Sistema de Diseño KDS en Figma

Este documento recopila ajustes y mejoras deseables que no son indispensables para la implementación inicial, pero que podrían mejorar la calidad, consistencia y usabilidad del documento de Figma generado automáticamente. Estas mejoras se aplicarán en iteraciones futuras una vez que la sincronización 100/100 esté completa.

## Mejoras para Colores
- **Ajustar anchos y espaciados de los grupos**: Revisar y optimizar el espaciado horizontal y vertical entre grupos de colores para una mejor legibilidad y organización visual. Considerar espaciados proporcionales basados en la escala de tokens.
- **Agrupar tokens por escala en tarjetas más parecidas al ejemplo**: Reorganizar la presentación de tokens de color en tarjetas que agrupen escalas (por ejemplo, primary, secondary, etc.) de manera más visual y similar al ejemplo proporcionado. Incluir miniaturas o previews más prominentes para cada escala.

## Mejoras Generales para Todos los Fundamentos
- **Consistencia en layouts**: Asegurar que todos los componentes maestros (typography, shadows, spacing, radius, etc.) sigan un patrón de layout consistente, con espaciados uniformes y alineaciones precisas.
- **Interactividad y navegación**: Agregar navegación interna en el documento de Figma para facilitar el acceso a diferentes secciones de fundamentos.
- **Validación automática**: Implementar checks automáticos para validar que los tokens aplicados coincidan exactamente con el SAAS de KDS.
- **Documentación integrada**: Incluir tooltips o descripciones emergentes en componentes para explicar el uso de cada token.
- **Optimización de rendimiento**: Revisar el tamaño del documento y optimizar la carga de assets (imágenes, fuentes) para un mejor rendimiento en Figma.

## Mejoras para Tipografía
- **Previews dinámicos**: Mostrar ejemplos de texto con diferentes pesos y tamaños aplicados en tiempo real.
- **Alineación con line-heights**: Asegurar que los ejemplos muestren line-heights correctos para evitar solapamientos.

## Mejoras para Sombras
- **Previews visuales**: Incluir miniaturas de cómo se ven las sombras aplicadas a elementos básicos.
- **Variaciones interactivas**: Permitir toggles para ver sombras en diferentes contextos (oscuro/claro).

## Mejoras para Espaciados y Radios
- **Ejemplos contextuales**: Mostrar espaciados aplicados en layouts reales en lugar de solo valores numéricos.
- **Escalas visuales**: Representar radios y espaciados en escalas visuales para una comprensión más intuitiva.

## Notas Adicionales
- Estas mejoras se priorizarán basadas en feedback de usuarios y necesidades del equipo de diseño.
- Se documentarán cambios implementados en este archivo para tracking.
- Considerar automatización adicional para aplicar estas mejoras sin intervención manual.
